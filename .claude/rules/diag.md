# 진단 도구(kra-diag) 규칙
- 보고서(json·txt)에는 집계만: 문서 내용·경로·파일명·사용자명·컴퓨터명·파일 바이트 금지(INC-010). 항목을 추가하면 `crates/diag/tests/report.rs` 에 경우를 추가한다.
- PC 를 바꾸지 않는다: 레지스트리·파일 암호화·인증서 생성 금지(DEC-022, INC-012 EFS 점검).
- 중간에 멈춰도 결과가 남아야 한다(단계마다·200파일마다 원자적 저장), 쓸 수 없는 폴더면 대체 폴더(INC-012).
- 사용자가 실행하는 것은 폐쇄망 PC 의 비전문 사용자다 — 메시지는 한국어로 원인과 할 일을 말한다.
