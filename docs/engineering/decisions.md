# 구현 판단 기록

스펙·계획이 정하지 않은 것을 구현 중에 정한 기록. 제품 설계 결정은 [스펙](../superpowers/specs/2026-10-12-kra-search-design.md)과 [UI 결정](../design/ui-decisions.md)에, M0 수치 기반 잠정 결정(양자화·차원·청크 크기·후보 수)은 [docs/m0/results.md](../m0/results.md)에 있다 — 여기에 되풀이하지 않는다.

형식: **판단 — 이유 — 틀렸을 때의 비용**. 상태: `유효` / `대체됨(→ DEC-xxx)` / `잠정`.
뒤집을 때는 지우지 말고 상태를 바꾸고 새 항목을 추가한다.

| DEC-009 | 실패 유형에 `FailKind::Drm`(Fasoo `\x9b DRMONE`, SoftCamp `SCDSA`, rhwp DRM 오류) | 스펙 §6.5, DRM 을 "HWP 아님"과 구분 | 없음 | 유효 |
| DEC-010 | 어댑터가 rhwp `rag::build_chunks` 출력(마크다운 표)을 해석 | 계획이 순회 방식을 정하지 않음 | — | **대체됨(→ DEC-027)** — INC-011 |
| DEC-027 | 어댑터는 rhwp 문서 모델을 직접 순회(`walk.rs`). 제목 판정만 `build_structure`. 머리말·꼬리말은 색인하지 않음. 1행·1열 표(글상자 대용)와 20만 칸 초과 표는 셀 문단을 그대로 문단으로. 세로 병합 셀은 40자 이하(이름표)만 아래 행에 되풀이, 가로 병합은 머리 행에서만 펼침. 셀 안 개체(중첩 표·글상자)는 표 뒤에 이어서 | INC-011. 이름표 되풀이는 "구분: 인건비" 같은 행 맥락을 살리고, 긴 본문 셀 되풀이는 중복만 늘림 | 머리말의 문서번호 등을 못 찾음(KI-013) | 유효 |
| DEC-028 | 추출 커버리지 = rhwp 조판 페이지 텍스트의 줄(글자·숫자만, 5자 이상)이 우리 텍스트에 포함되는 글자 비율. 줄 앞 숫자(자동 번호)는 떼고 재비교. kra-diag 는 최대 500개 고른 표본·5MB 이하 파일만 | 조판 결과를 "정답"으로 쓰는 가장 싼 방법. 조판은 느려 표본만 | rhwp 조판 자체가 빠뜨리는 글자는 못 잡음(KI-016) | 유효 |
| DEC-030 | 공공누리 제1유형 공개 문서 3개를 추출 시험 고정 자료로 저장소에 포함 | 글상자·조문·바이너리 HWP 회귀를 실제 문서로 잡기 위해(합성 문서로는 글상자 회귀가 안 잡혔음) | 저장소 약 1.1MB 증가 | 유효 |
