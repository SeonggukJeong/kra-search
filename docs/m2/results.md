### 1.3 카드 상한 판정(결정 #27, KI-041)
- 128 에서 잘리는 카드 35/1,058(3.3%) < 25% → **판단 불가, 256 유지**. 조정용 nDCG 차이(128−256) +0.0000, 마사회 유형 kra·kra-deep·kra-plain 모두 +0.0000.
- 이 0 은 측정값이 아니라 구조적 0 이다: 결합이 ChunkElseCard 라 카드는 청크가 없는 문서에만 쓰이고, 평가는 청크가 다 있는 상태에서 잰다. 색인 초기(카드만 있을 때)의 영향은 재지 않았다 — 카드 속도(KI-041) 판단 근거로 쓰지 않는다.

### 1.4 데이터 형식 뒷부분(본문 ③)

데이터 형식 문서 48개는 고정 시드 생성기로 만든 **합성** 문서다(DEC-055, `eval/data/README.md`) — 실제 업무 데이터 파일에서의 영향은 폐쇄망 확인에서 본다.

| 유형(전체) | 켬 nDCG@10 · 첫 페이지 | 끔 nDCG@10 · 첫 페이지 |
|---|---|---|
| data-deep(정답이 앞 20청크 뒤, 8개) | 0.5452 · 75.0% | 0.3592 · 62.5% |
| data-head(정답이 앞부분, 4개) | 0.3467 · 50.0% | 0.4717 · 75.0% |

- 조정용 데이터 아닌 질의 매크로 차이(켬−끔) +0.0005 — 규칙(−0.3%p 이상 하락이면 끔 안을 올림)에 걸리지 않아 **켬 유지**. 켜면 뒷부분 청크가 앞부분 정답과 경쟁해 data-head 가 떨어진다(질의 4개).

## 2. 일치 검사 (docs/m2/parity.md, DEC-059)

| 항목 | 값 | 기준 | 판정 |
|---|---|---|---|
| (i) 같은 벡터 → 상위 100 이 순서까지 같은 질의 | 255/255 | 100% | 통과 |
| (ii) 입력 벡터 최소 코사인 | 카드 0.999427(1,058개) · 청크 0.999164(22,473개) · 검색어 1.000000(255개), 0.999 미만 0개 | ≥ 0.999 | 통과 |

- 일치 검사 중 발견해 고친 것: **INC-021** — 키워드 점수가 같은 문서의 순서가 tantivy 세그먼트 배치(무작위)에 따라 달라짐 → (점수, 내용 id) 로 정렬. 같은 수정 시각 파일의 내용 id 를 경로 순서로 매김(DEC-059).
- eval-hybrid.md 는 (iii) 첫째 행과 같이 하나씩 임베딩한 검색어 벡터로 만든다. 둘째 행(8개씩 묶음)은 묶음 잡음의 크기를 보이는 참고 행이다.

## 3. 성능

### 3.1 검색 코어(합성 벡터, Task 19)
- 청크 50만 · 카드 1만: **p50 2.9ms · p95 3.5ms**(`crates/index/tests/bench_hybrid.rs`, 검색어 임베딩 제외). 기준(의미 포함 p95 ≤ 500ms)에 여유가 크다. 검색어 임베딩 포함 지연은 폐쇄망 확인에서 잰다(m1-diag-2 의 검색어 임베딩 Q8 p95 62ms).
- 검색 준비(MapMeta 만들기) 내용 5만 건: 143ms(title_texts 54 · title_years 73 · newest_mtimes 10 · chunked_contents 5ms, `crates/app/tests/bench_open.rs`, 합성 데이터 — 제목 1/3 에 연도, 짧은 경로, 제목 없는 내용 없음).

## 5. M3 에 넘길 것
- KI-042: 명령줄 `search` 의 벡터 메모리 읽기(청크 50만 ≈ 300MB) → 상주 전 메모리 매핑 또는 검색 후 해제.
- KI-048: 검색마다 모델·meta(수정일·청크 여부) 읽기 → 상주 앱에서 한 번만.
- KI-049: 내용 시기 질의의 날짜 가산 하락 → 📅 칩 ✕ 로 가산 끄기(`ui-decisions.md`), 안내 문구 검토. 근본 대책은 M4 시행일·§16 기타 아이디어(본문·속성 날짜).

- KI-051(형식이 바뀐 경로의 청크 위치) · KI-053(청크 파일만 못 읽어도 의미 검색 전체 꺼짐) — 구절 미리보기·검색창 작업 때.
- KI-054: 상주 앱에서 옛 세대 벡터 파일이 쌓임(M5 상주 앱 전에 정리 주기).
