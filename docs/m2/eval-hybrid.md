# M2 하이브리드 평가 (자동 생성: `cargo run -p m0eval --release -- --hybrid --eval eval/public --eval eval/kra --eval eval/data`)

- 문서 1062건 · 질의 255개(조정용 155 · 검증용 100) · 기준 시점 2026-10-15 · 카드 상한 256 · 실험과 제품이 같은 검색 코어(index::hybrid)
- 첫 페이지 적중 = 정답 문서가 하나라도 상위 10 안(사용자 원칙: "항상 최상위가 아니어도 첫 페이지에 정확한 결과를"). 적중률 = 질의 비율.
- 일치 검사(실험 = 제품): `docs/m2/parity.md` (`--parity <앱 덤프>` 로 만든다, DEC-052)

## 결정 규칙(숫자로만, DEC-051)

- 값은 조정용 질의(qid 해시, 유형마다 60%)로만 고르고, 합격 판정은 검증용(40%)으로만 한다. 목표 = 조정용 유형별 매크로 nDCG@10. "참고(전체)" 숫자는 판정에 쓰지 않는다.
- 좌표 하강: 한 축씩 후보를 견줘, 조정용 매크로 nDCG@10 이 지금보다 0.005 넘게 높고 **조정용 첫 페이지 적중 수가 줄지 않는** 후보 중 가장 높은 것으로 바꾼다. 한 회차를 다 돌아 바뀐 것이 없으면 멈춘다(상한 10회차).
- 유형 나누기(keyword_max_chars): 나누는 쪽(문턱 6·8·10)과 나누지 않는 쪽(0)을 각각 좌표 하강으로 끝까지 고른 뒤, 나누는 쪽이 같은 채택 규칙(+0.005 넘게, 첫 페이지 적중 줄지 않음)으로 이길 때만 나눈다. 아니면 0 쪽의 값 전체를 쓰고 키워드형 가중치([0])는 의미형([1])과 같게 둔다.
- 날짜 표현 빼기: 종류마다 조정용 temporal 로 견줘, 차이가 0.005 이내면 기본값, 빼는 쪽이 0.005 넘게 높고 첫 페이지 적중이 줄지 않으면 뺀다, 그 밖에는 빼지 않는다.
- 카드 상한 128(결정 #27): 128에서 잘리는 카드(문서 기준)가 25% 미만이면 판단 불가(256), 조정용 전체 nDCG −0.003 이하 또는 마사회 유형 −0.01 이하 하락이면 256, 아니면 128.
- 데이터 뒷부분(본문 ③): 켰을 때 조정용 데이터 아닌 질의 매크로가 0.3%p 이상 떨어지면 기본 끔 안을 사용자에게 올린다.
