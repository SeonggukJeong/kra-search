KRA 문서검색 — 폐쇄망 품질 확인 (M2)

이 프로그램은 PC 안에서만 동작하고 아무것도 밖으로 보내지 않습니다.
색인은 %LOCALAPPDATA%\KraSearch 에 만들어집니다(확인이 끝나면 그 폴더를 지워도 됩니다).

1. 압축을 풉니다(예: D:\kra-check). 폴더 안에서 주소창에 cmd 를 쳐 명령 프롬프트를 엽니다.
2. 색인: kra-search.exe index --root "D:\업무문서"
   - 화면에 "빠른 의미 검색 n/N · 정밀 의미 검색 n/N" 이 늘어납니다. 끝까지 기다립니다(문서가 많으면 몇 시간).
   - 중간에 꺼도 다시 같은 명령을 치면 이어서 합니다.
     껐다가 이어서 했다면 그 사실과 대략 걸린 시간을 보고서와 함께 알려 주세요
     (보고서의 색인 시간은 마지막 실행 한 번의 기록입니다).
   - 색인이 끝난 뒤에는 평가 전에 index 를 다시 치지 마세요(색인 시간 기록이 새 실행으로 바뀝니다).
3. 질의 파일 만들기: 메모장에서 한 줄에 하나씩
       찾고 싶은 말<Tab>정답 파일 이름
   예) 작년 적극행정 추진계획<Tab>2025년 적극행정 추진계획(안).hwp
   - 20~30줄. 평소 찾는 말 그대로 써 주세요.
   - "작년·지난달·올해 상반기"처럼 날짜 표현을 넣은 줄도 섞어 주세요. 두 가지를 다 넣어 주세요.
       · 날짜가 "문서를 쓴 때"인 것: 작년 ○○ 계획, 지난달 ○○ 보고
       · 날짜가 "내용의 기간"인 것(몇 줄이면 됩니다): 작년 ○○ 실적, 상반기 ○○ 결과
         (작년 실적 보고는 보통 올해 쓰입니다. 이런 질의가 날짜 때문에 밀리는지 보고서가 따로 비교합니다.)
         보고서를 가져올 때 "내용의 기간" 질의가 몇 번째 줄인지 줄 번호만 함께 알려 주세요.
   - 정답 파일이 여러 개면 쉼표로: 파일1.hwp, 파일2.pdf
     탭을 한 번 더 누르고 이어 써도 됩니다: 파일1.hwp<Tab>파일2.pdf
   - 파일 이름에 쉼표가 들어 있어도(예: 1,2분기 실적.hwp) 그대로 쓰면 됩니다.
     그런 파일이 정답 여러 개 중 하나면 그 파일은 탭으로 칸을 나눠 따로 써 주세요.
   - 같은 이름의 파일이 다른 폴더에도 있으면(예: 붙임1.hwp) 앞에 폴더 이름을 붙여 주세요.
       예) 2025년\붙임1.hwp
     보고서에 "정답 이름이 여러 파일과 맞은 질의"의 줄 번호가 나오면 그 줄에 폴더 이름을 붙여 다시 평가하면 됩니다.
   - 탐색기에 확장자(.hwp)가 안 보이면 이름만 써도 됩니다.
   - 다른 이름으로 저장 → 인코딩 UTF-8 → 내질의.tsv (명령 프롬프트를 연 폴더에 저장)
   - 질의-예시.tsv 를 고쳐 써도 됩니다(첫 줄 "질의<Tab>정답" 은 그대로 두어도 됩니다).
4. 평가: kra-search.exe eval --queries 내질의.tsv
   - 결과가 화면에 나오고, 같은 내용이 명령 프롬프트를 연 폴더에 kra-search-eval-report.txt 로 저장됩니다
     (다시 평가하면 덮어씁니다). 이 파일만 반출합니다.
   - 보고서에는 검색어·파일 이름·경로·문서 내용이 없습니다(줄 번호와 숫자만). 반출 전에 메모장으로 열어 확인해 주세요.
   - 보고서의 줄 번호는 질의 파일의 줄 번호입니다(맨 윗줄이 1, 메모장 아래쪽의 "줄" 표시와 같음).
   - "정답 파일을 색인에서 찾지 못한 질의"나 "읽지 못한 질의 파일 줄"이 있으면 그 줄의 파일 이름·탭을 고쳐 다시 평가해 주세요.
   - 파일을 저장하지 못했다는 안내가 나오면 화면 내용을 복사해 메모장에 붙여 넣어 가져와도 됩니다.
5. (선택) 검색해 보기: kra-search.exe search 찾고 싶은 말
