결과가 단계적으로 바뀔 때, 어떻게 알려 줄까요?

상황: 키워드 결과가 먼저 나오고, 0.4초 뒤 의미 검색 결과가 합쳐지는 순간입니다. 아래 미리보기는 실제로 움직입니다(3초마다 반복).

A

배지 + 색 띠 (즉시 반영)

새 결과가 순간적으로 끼어들고, 주황색 띠와 ✨ 배지가 2초 동안 보였다가 사라집니다. 위로 올라간 항목에는 ▲2 같은 표시가 붙습니다. 정보는 분명하지만 목록이 "툭" 바뀝니다.

사용자가 아직 목록을 건드리지 않았으면 B처럼 자동으로 합칩니다. 방향키나 마우스로 목록을 보기 시작한 뒤에는 목록을 그대로 두고, 위쪽에 "의미 검색 결과 1개 더 · 여기서 Enter로 반영" 배너만 띄웁니다. 목록 맨 위에서 ↑를 누르면 배너로 이동하고 Enter로 반영합니다(클릭도 가능). 보고 있던 화면이 절대 바뀌지 않습니다.
