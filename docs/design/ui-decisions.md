# UI/UX 결정 기록

> 구현 시 이 문서가 화면 동작의 기준이다. 목업(`mockups/`)과 이 문서가 다르면 **이 문서가 우선**한다.

## 확정된 결정

### D1. 메인 검색창 레이아웃 = 적응형 (2026-10-12 확정, 2026-10-13 개정)
- 목업: `mockups/search-layout.html` 의 **C안** (A·B는 C의 상태로 흡수됨)
- 여는 방법: 전역 단축키 **`Alt+Space`**, **트레이 아이콘 클릭**, 시작 메뉴 아이콘 — 모두 같은 검색창을 연다.
- 처음 열면 검색줄 한 개만 있는 작은 창 (A 상태). 플레이스홀더: "무엇을 찾으세요? 예: 작년 예산 관련 공문"
- 결과가 나오면 **목록 + 미리보기 2분할**로 넓어짐 (B 상태). 사용자가 조절한 창 크기를 기억한다.
- 작업 영역 폭이 1000px 미만이면 **목록 한 줄(단일 열)**로 표시하고, 미리보기는 목록에 포커스가 있을 때 `Space`로 연다/닫는다.
- 설정 "결과 미리보기 패널": 자동(화면 폭, 기본) / 항상 / 목록에서 Space로.
- 검색줄 아래 필터 칩: 📅 날짜 칩(검색어에서 인식, ✕로 해제), 형식, 기간, 🛡 개인정보, **`필터 더보기 ▾`**(공문 시행일, 수신처·발신 기관, 폴더, 🔒 보안 문서).
- 목록 오른쪽 위: 정렬 전환 `관련도순 ▾ / 최신순`.
- 결과 행: 형식 아이콘, 제목(공문 제목 우선, 없으면 파일명), 경로·수정일(공문이면 문서번호·시행일·수신), 일치 구절 하이라이트, 배지(`버전 N개 ▾`, `🛡 유형 개수`, `🔒`).
- 미리보기 패널: 제목, 경로, 수정일·형식·쪽수, 버전 목록, 일치한 구절(쪽/표 위치 표시, D8 마스킹), 버튼 [열기] [폴더 열기] [경로 복사], 하단 **"왜 이 결과?"** 한 줄.
- 키보드 (포커스 위치별)
  - 검색 입력칸: 글자 입력(Space = 띄어쓰기) · `↑↓` 목록 선택 이동(포커스는 입력칸 유지) · `Enter` 선택 항목 열기 · `Ctrl+Enter` 폴더 열기 · `Tab` 목록으로 포커스 이동 · `Esc` 닫기
  - 결과 목록: `↑↓` 이동 · `Enter` 열기 · `Ctrl+Enter` 폴더 열기 · `Space` 미리보기 열기/닫기 · 맨 위 항목에서 `↑` → 대기 배너(D2)로 포커스 · 아무 글자 입력 시 검색 입력칸으로 복귀 · `Tab`/`Shift+Tab` 표준 포커스 이동 · `Esc` 닫기
- 바닥글 도움말: `↑↓ 이동 · Enter 열기 · Ctrl+Enter 폴더 열기 · Tab 목록으로`

### D2. 단계적 결과 표시와 순서 변경 UX = "부드러운 이동 + 대기 배너" (2026-10-12 확정, 2026-10-13 개정)
- 목업: `mockups/reorder-ux.html` 의 **C안**
- 결과는 단계적으로 표시: 파일명(즉시) → 키워드(입력 멈춤 150ms 후) → 의미 검색(완료 후).
- **사용자가 목록을 아직 건드리지 않았을 때**: 새 결과를 자동 병합. 기존 항목은 200ms 미끄러지듯 이동, 새 항목은 위에서 살짝 내려오며 테두리가 한 번 빛남. 배지는 남기지 않음.
- **사용자가 방향키/마우스로 목록을 보기 시작한 뒤**: 목록을 절대 바꾸지 않는다. 목록 위에 배너 **"↑ 의미 검색 결과 N개 더 · 여기서 Enter로 반영"**만 표시.
- 배너 반영 방법: **목록 맨 위 항목에서 `↑` → 배너에 포커스 → `Enter`**, 또는 배너 **클릭**.
- 선택(강조)된 항목은 어떤 경우에도 위치가 바뀌지 않으며, 목록에 포커스가 있을 때 `Enter`는 항상 강조된 항목을 연다.
- 상단 진행 표시: `의미 검색 중…` → 완료 시 `✔ 검색 완료` 후 사라짐.
- Windows "애니메이션 효과 끄기"가 켜져 있으면 애니메이션 없이 즉시 반영 + 배너만.
- 화면 낭독기에는 aria-live로 "의미 검색 결과 N개 추가" 안내.

### D3. "왜 이 결과?" (2026-10-12 확정)
- 미리보기 패널 하단 한 줄. 예: `키워드 일치 3곳(제목 1) · 뜻이 비슷함 · 2025년 문서`

### D4. 요약/질의응답(2차)은 별도 창 (2026-10-12 확정)
- 검색창은 단순하게 유지. 2차에 미리보기 패널에 `요약` 버튼, 다중 선택 시 `이 문서들로 질문하기` 버튼만 추가.
- "문서 도우미"는 별도 Tauri 창. 검색창에서 선택한 문서(문서 ID + 청크 ID 목록)를 넘겨받아 시작.
- 1차 구현 범위: 다중 창 구조와 "문서/청크 ID 목록" 전달 계약까지만. 화면은 만들지 않는다.

### D5. 나머지 화면 ①~⑦ (2026-10-12 확정, 2026-10-13·2026-10-15 개정)
- 목업: `mockups/other-screens.html`
- ① 첫 실행: 범위(모든 로컬 드라이브·대상 형식·제외 목록·[범위 변경…]), 발견 문서 수 + 단계별 예상 시간("키워드 검색 약 N분 · 빠른 의미 검색 약 N분 · 정밀 의미 검색은 PC를 쓰지 않을 때 계속"), PC 성능 감지 → 프로필(저사양/보통/고성능) 추천, 저사양이면 상주 모드 끄기 권장, [나중에] [색인 시작]. "이 PC 안에서만 처리되고 외부로 나가지 않습니다" 문구 필수.
- ② 트레이: **아이콘 왼쪽 클릭 = 검색창 열기**. 오른쪽 클릭 메뉴 순서: 검색 열기(단축키 표시) / ─ / 색인 일시 정지 ▸(1시간·오늘) / 색인 현황(정밀 의미 검색 %) / 개인정보 점검(개수) / 설정 / ─ / 종료. 아이콘: 색인 중 회전 점, 일시 정지 ⏸.
- ③ 단축키 충돌: 기본 `Alt+Space` 등록 실패 시 대화상자 → 대안 `Ctrl+Alt+Space`(기본 강조), [직접 지정…]. 직접 지정 시 `Win+Space`(Windows 입력 언어 전환 예약)·`Ctrl+Space`(엑셀 열 선택) 등 알려진 충돌 조합은 경고.
- ④ 색인 현황: 진행률 3줄(키워드 검색 / 빠른 의미 검색 / 정밀 의미 검색 N%) + 정밀 의미 검색 아래 한 줄 "텍스트·CSV·엑셀 파일 뒷부분"(켜짐: `PC를 쓰지 않을 때 계속 (N%)` / 꺼짐: `텍스트·CSV·엑셀 파일은 앞부분만 정밀 검색합니다 [뒷부분까지 켜기]`). 정밀 의미 검색 N%는 문서 형식 전체 + 데이터 형식 앞부분만 센다(스펙 §6.6 본문 3단 순서), 형식별 문서 수, 읽지 못한 파일(🔒 보안 문서(DRM) · 🔑 암호 문서 · ⚠ 열 수 없는 파일 · ⏱ 시간 초과·너무 큰 파일, 클릭 시 목록), "색인 데이터 암호화: 적용됨/적용 안 됨", 색인 크기, "파일 이름 검색 엔진: 실행 중", [일시 정지] [다시 색인…]. 암호화 불가 시 ⚠ 안내 문구. 기술 정보는 [자세히] 아래.
- ⑤ 개인정보 점검: 위험도순 표(위험도·파일/경로·포함 항목 개수·수정일·[폴더 열기]), 유형 필터(전체/주민번호/외국인·여권·면허/계좌/휴대폰·이메일). **번호 값은 절대 표시하지 않음.** 위험도 = 유형 가중치(주민번호 > 외국인·여권·면허 > 계좌 > 휴대폰 > 이메일) × 개수.
- ⑥ 설정 탭: 일반 / 색인 범위 / 성능 / 모델(D6) / 약어 사전 / 개인정보·보안 / 정보. 일반 탭: 검색 단축키, 상주 모드, Windows 시작 시 실행, 테마, 결과 미리보기 패널. 🔒 기관 정책 잠금 항목 표시. 성능 탭: 체크박스 `텍스트·CSV·엑셀 파일 뒷부분까지 정밀 의미 검색`(기본 켬, 저사양 프로필 기본 끔) + 옆에 "이 PC 예상: PC를 쓰지 않는 시간 약 N시간 · 저장 공간 약 N MB".
- ⑦ 접근성: 키보드 전용 사용, 포커스 테두리 상시, ARIA + aria-live, 고대비·125~200% 배율, 색+글자 병기, 애니메이션 끄기 설정 존중.

### D6. 설정 > 모델 탭 (2026-10-12 확정, 2026-10-13 개정)
- 목업: `mockups/model-settings.html`
- 슬롯 2개: 🔍 검색용 모델(1차) / 💬 요약·질의응답 모델(2차 — 1차에선 비활성 자리만).
- 기본 모델 EmbeddingGemma 2는 설치파일에 포함. 추가 모델은 로컬 GGUF 파일 선택(다운로드 없음). 기관 정책으로 추가 기능을 막을 수 있음(🔒).
- 표시 항목: 모델 이름, "이 PC 처리 속도"(실측값, 쉬운 단위: "문서 카드 1만 개 약 N분"), 메모리.
- 추가 시 자동 검사: 불러오기 → 모델 정보 → 예문 검사 → 이 PC 속도.
- 전환: 새 의미 검색 색인(빠른 → 정밀)을 백그라운드에서 별도 생성, 완료 시 한 번에 교체. 진행 중엔 기존 모델로 검색. 키워드 색인은 재사용. 이전 색인 보관 → [이전 모델로 되돌리기] / [이전 색인 삭제].

### D7. 사용성 원칙과 쉬운 용어 (2026-10-13 확정)
- 사용자는 `KRA 문서검색` 아이콘 하나만 안다. 워커·서비스는 화면·작업 안내 어디에도 이름이 나오지 않는다.
- 자동 복구되는 문제(워커·서비스 재시작, 재색인)는 오류 창을 띄우지 않고 색인 현황 [자세히]에만 기록.
- 화면 용어 대응표 (왼쪽 단어는 화면에 쓰지 않는다)

| 내부 용어 | 화면 문구 |
|---|---|
| 임베딩, 벡터 | 의미 검색 |
| 문서 카드 임베딩(2단계) | 빠른 의미 검색 |
| 본문 청크 임베딩(3단계) | 정밀 의미 검색 |
| BM25, 키워드 색인 | 키워드 검색 |
| 청크 | (표시하지 않음) 필요 시 "구절" |
| EFS, SQLCipher, DPAPI | 색인 데이터 암호화 |
| DRM | 보안 문서 |
| 추출 실패 | 열 수 없는 파일 |
| 파일명 엔진 서비스 | 파일 이름 검색 엔진 |
| 유휴 | PC를 쓰지 않을 때 |
| GGUF, 양자화 | (모델 탭 [자세히] 아래에만) |

### D8. 개인정보 마스킹 표시 (2026-10-13 확정)
- 미리보기·일치 구절에서 식별번호는 **숫자 없이** 자리 모양만 표시: 주민·외국인등록번호 `●●●●●●-●●●●●●●`, 휴대폰 `●●●-●●●●-●●●●`, 계좌 `●●●●…`, 여권·면허 `●●●●…`, 이메일 `●●●@●●●`.
- 마스킹 부분에 마우스를 올리면 툴팁 "개인정보(주민번호)는 표시하지 않습니다. 원본 파일에서 확인하세요."

## 변경 이력
- 2026-10-13: 리뷰 반영 — 단축키 `Ctrl+Space`→`Alt+Space`(엑셀 열 선택과 충돌, Win+Space는 Windows 예약). 대기 결과 반영 `Tab`→"↑로 배너 이동 후 Enter"(Tab은 포커스 이동 표준 키). Space는 목록 포커스에서만 미리보기. 필터 더보기·정렬 위치 지정. 트레이 클릭 열기. D7(쉬운 용어)·D8(숫자 없는 마스킹) 추가. 의미 검색 2단계(빠른/정밀) 표시 반영.
- 2026-10-15: 사용자 승인(M2 설계) — D5 ④ 색인 현황에 "텍스트·CSV·엑셀 파일 뒷부분" 줄과 꺼짐 시 [뒷부분까지 켜기], ⑥ 성능 탭에 같은 설정 체크박스와 이 PC 예상 시간·저장 공간. 데이터 형식 본문의 뒷부분(본문 3단 순서의 3)을 끌 수 있게 하면서 꺼진 상태를 사용자가 알 수 있게 하려는 것. 검색 결과 안 안내("앞부분만 찾음")는 화면이 복잡해져 넣지 않음.
