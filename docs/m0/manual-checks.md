# M0 수동 점검 (폐쇄망 PC)

## 1. 단축키 충돌 (kra-diag를 실행하지 않은 상태에서)
아래 프로그램에서 문서를 하나 열고, 창이 활성화된 상태로 각 조합을 누른다.
"창 왼쪽 위 메뉴(이동/크기 조정/최소화…)가 뜨거나 아무 반응 없음"이면 ✔, 프로그램 고유 기능이 실행되면 ✘와 그 기능을 적는다.

| 프로그램 | Alt+Space | Ctrl+Alt+Space |
|---|---|---|
| 한글 | | |
| 한셀 | | |
| 한쇼 | | |
| Word | | |
| Excel | | |
| PowerPoint | | |
| 사내 그룹웨어/전자결재(브라우저) | | |

## 2. 백신 반응
zip을 풀 때와 `kra-diag.exe` 실행 중 백신 경고가 있었는지, 있었다면 백신 이름과 메시지를 적는다.

## 3. 결과 전달
- kra-diag-summary.txt 내용(또는 옮겨 적은 요약)
- 위 표
- 사용 PC 사양을 알면 함께(예: i5-8500 / 8GB)
