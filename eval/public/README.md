# 공개 평가 세트 (M0)

검색 품질(모델 설정·청크 크기·차원·결합 방식)을 수치로 비교하기 위한 공개 한국어 문서와 질의.

## 문서
- 출처: 정책브리핑(korea.kr) 보도자료 첨부 HWPX — **공공누리 제1유형(출처표시)** 표시가 있는 것만, 보도자료당 1개.
- 수집: `python3 tools/eval/collect_korea_kr.py --target N` (요청 간 1초, robots.txt 전체 허용). 개별 추가는 `tools/eval/add_doc.py`.
- 원본 파일은 저장소에 넣지 않는다(`eval/public/docs/`는 gitignore). `python3 tools/eval/fetch_all.py`로 다시 받고 SHA-256을 검증한다.
- 2026-10-13 수집: 200건(2026-10-06~12 게시분), 전부 HWPX. 추출 성공 199, **P0126은 암호 문서**(공개 문서인데도 암호가 걸린 실제 사례).
- 본문 길이(추출 텍스트): 중앙값 약 1,900자, p90 약 6,600자, 최대 약 27,000자.

### 한계
- 보도자료라 대부분 1~5쪽이다. 50쪽 이상 계획서·규정집이 거의 없어 **긴 문서의 청크 크기 효과는 과소평가**될 수 있다.
- HWP(바이너리)가 없다. HWP 바이너리 추출 성공률은 폐쇄망 진단(`kra-diag`)과 테스트 샘플로 따로 본다.
- 같은 내용이 부처별로 중복 게시된 경우가 있다(예: P0018/P0019, P0044/P0074). 질의 정답에 모두 넣었다(버전 묶기 시험에도 쓸 수 있음).

## 질의 (`queries.tsv`)
열: `qid`, `query`, `type`, `relevant`(쉼표 구분 문서 id).

| 유형 | 개수 | 작성 규칙 |
|---|---|---|
| `semantic` | 40 | 공무원이 실제로 칠 법한 문장. 문서 문장을 베끼지 않고 바꿔 말함 |
| `keyword` | 30 | 2~6글자 고유명사·사업명·약어. 전체 문서에서 해당 표현을 포함한 문서는 모두 정답(검사 스크립트로 확인) |
| `abbrev` | 15 | 부처·기관 약칭(과기정통부, 행안부, 농진청 등) + 주제 |
| `temporal` | 15 | "올해 3분기", "다음 주", "10월 초순" 같은 시점 표현 포함 |

- 키워드형 중 Q057(가져가 앱)·Q059(헤이모던시티)·Q061(감초 원감)은 문서 표기와 띄어쓰기·문장부호가 다르다(일부러 넣은 변형).
