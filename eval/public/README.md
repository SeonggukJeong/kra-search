# 공개 평가 세트 (M0)

검색 품질(모델 설정·청크 크기·차원·결합 방식)을 수치로 비교하기 위한 공개 한국어 문서와 질의.

## 문서
- 출처: 정책브리핑(korea.kr) 보도자료 첨부 HWPX — **공공누리 제1유형(출처표시)** 표시가 있는 것만, 보도자료당 1개.
- 수집: `python3 tools/eval/collect_korea_kr.py --target N` (요청 간 1초, robots.txt 전체 허용). 개별 추가는 `tools/eval/add_doc.py`.
- 원본 파일은 저장소에 넣지 않는다(`eval/public/docs/`는 gitignore). `python3 tools/eval/fetch_all.py`로 다시 받고 SHA-256을 검증한다.
- 2026-10-13 수집: 1차 200건(10-06~12 게시분) → 1차 평가가 천장 효과(모든 설정 nDCG@10 ≥ 0.98)로 변별력이 없어 **2차 800건 추가(총 1,000건, 9월 초~10월 게시분)**. HWPX 965 · HWP 35. 추출 실패 3건은 모두 **암호 문서**(P0126, P0404, P0702 — 공개 문서인데 암호가 걸린 실제 사례).
- 본문 길이(추출 텍스트): 중앙값 약 1,900자, p90 약 6,600자, 최대 약 27,000자.
- **문서 날짜**(`date`, 2026-10-15 추가): korea.kr 보도자료 게시일. `python3 tools/eval/fetch_dates.py` 가 채운다. 평가에서는 이 날짜를 파일 수정일로 둔다(M2 날짜 가산 평가, DEC-055). 게시일 범위는 2026년 9~10월이라 "작년" 같은 표현은 마사회 세트에서만 시험된다.

### 한계
- 보도자료라 대부분 1~5쪽이다. 50쪽 이상 계획서·규정집이 거의 없어 **긴 문서의 청크 크기 효과는 과소평가**될 수 있다.
- HWP(바이너리)가 없다. HWP 바이너리 추출 성공률은 폐쇄망 진단(`kra-diag`)과 테스트 샘플로 따로 본다.
- 같은 내용이 부처별로 중복 게시된 경우가 있다(예: P0018/P0019, P0044/P0074). 질의 정답에 모두 넣었다(버전 묶기 시험에도 쓸 수 있음).

## 질의 (`queries.tsv`)
열: `qid`, `query`, `type`, `relevant`(쉼표 구분 문서 id). `date` 유형만 5번째 열 `range`(`YYYY-MM-DD..YYYY-MM-DD` 또는 미래 표현이면 `future`)가 있다.

| 유형 | 개수 | 작성 규칙 |
|---|---|---|
| `semantic` | 40 | 공무원이 실제로 칠 법한 문장. 문서 문장을 베끼지 않고 바꿔 말함 |
| `keyword` | 30 | 2~6글자 고유명사·사업명·약어. 전체 문서에서 해당 표현을 포함한 문서는 모두 정답(검사 스크립트로 확인) |
| `abbrev` | 15 | 부처·기관 약칭(과기정통부, 행안부, 농진청 등) + 주제 |
| `temporal` | 15 | "올해 3분기", "다음 주", "10월 초순" 같은 시점 표현 포함 |
| `deep` | 30 | 제목·첫 문단이 아니라 **본문 중간**(표·세부 수치·부대 내용)에 있는 정보를 묻는 질의 |
| `date` | 30 | 오늘 기준(2026-10-15) 날짜 표현 + 주제. 5번째 열 = 표현의 기간. 주제만으로는 날짜가 다른 문서가 2개 이상 걸림. 한자어·구어·약식 표현을 섞음(M2 설계 §5). 공개·마사회 세트에 나눠 있다(공개 17 · 마사회 13) |

- `date` 정답 = 주제 문서 중 날짜가 기간 안인 것(`future` 는 주제만으로). 단 제목에 연도가 있으면(2025년·25년·'25) 제목 연도가 파일 날짜보다 우선한다(사용자 요구 2026-10-15, 예: 작년 경마시행계획 → 2025년 계획). 연도도 상대어도 없는 되풀이 시기(연말·9월 말·3분기·10월 초 …)는 6번째 열에 `recurring` 을 쓰고, 해마다 같은 시기의 주제 문서가 모두 정답이다(예: "연말에 나온 경마 시행계획" = 2025·2024 연말에 나온 것 모두). 5번째 열은 그대로 가장 최근 시기(해석기 칩). 기간 열은 날짜 해석기(`crates/query`)의 결과와 같아야 한다(`crates/query/tests/eval_dates.rs` 가 확인). 공개 문서 게시일이 2026-09-23~10-12 뿐이라 해 단위 표현(작년·'25 등)은 마사회 세트에 있다.
- 키워드형 중 Q057(가져가 앱)·Q059(헤이모던시티)·Q061(감초 원감)은 문서 표기와 띄어쓰기·문장부호가 다르다(일부러 넣은 변형).
