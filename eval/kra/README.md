# 한국마사회 업무 문서 평가 세트

공개 보도자료 세트(`eval/public`)만으로는 실제 업무(규정·공문·신구대조표)를 대표하지 못하고, 사용자가 질의·정답을 판단하기 어렵다.
그래서 마사회가 **정보공개포털(open.go.kr) 원문정보**로 공개한 문서로 업무형 질의를 만든다. 공개 세트와 **합쳐서** 평가한다(공개 문서 1,000건이 방해 문서 역할).

## 문서
- 사용자가 open.go.kr → 기관찾기 "한국마사회" → 검색 → 공개 파일 다운로드로 받아 `eval/downloads/<건명>/` 에 둔다(gitignore).
- `manifest.toml` 에 id·제목·출처·SHA-256·`local`(eval/downloads 기준 경로)을 적고 `python3 tools/eval/import_local.py eval/kra` 로 `eval/kra/docs/`(gitignore)에 복사·검증한다.
- 공문 갑지(본문)는 PDF 로만 내려받을 수 있는데 M0 에는 PDF 추출이 없어 제외했다(KI-014). 붙임 HWP 만 쓴다. 인식조사의 붙임2(조사기관 보고서 원문)도 PDF 라 제외.

## 질의 (`queries.tsv`)
| 유형 | 개수 | 작성 규칙 |
|---|---|---|
| `kra` | 23 | 직원이 규정을 찾을 때 칠 법한 짧은 주제 질의 |
| `kra-deep` | 38 | 특정 조·항·호의 세부(임기·주기·인원·기한·예외)를 묻는 질의. 문장을 베끼지 않고 바꿔 말함 |
| `kra-plain` | 22 | 규정 용어를 모르는 다른 부서 직원의 일상 표현("징계 안 받는 경우", "업무 매뉴얼 최신으로"). 2026-10-13 사용자 의견으로 추가 |
| `date` | 13 | 날짜 표현 + 주제(기준일 2026-10-15). 5번째 열 = 표현의 기간. 작성 규칙은 `eval/public/README.md`(공개 세트와 합쳐 30개). "작년/올해 경마시행계획" 같은 날짜 함정 포함 |

**date 정답의 제목 연도 규칙**: 제목에 연도가 있으면(2025년·25년·'25) 그 연도가 파일 날짜(`date`)보다 우선한다 — 2026년에 "작년 경마시행계획"을 물으면 2025년 경마시행계획(K0014)이 정답이다(사용자 요구 2026-10-15). 정답 문서는 날짜가 기간 안이거나 제목 연도가 기간과 겹쳐야 한다(`tools/eval/check_sets.py` 가 확인). 연도 없는 되풀이 시기 표현(연말·N월·N분기·상반기·계절)은 6번째 열 `recurring` — 해마다 같은 시기에 든 주제 문서가 모두 정답이다(T003 연말 경마시행계획 = K0009·K0010·K0014).

정답: 그 정보를 직접 담은 문서. 개정안(K0001)은 바뀐 조문만 담고, 개정전문(K0002)은 전체를 담으므로 바뀌지 않은 조문은 K0002 만 정답이다. 요약(K0003)도 같은 원칙 — 항목 제목만 있고 내용(금액·비율·기한)이 없으면 정답이 아니다.

## 한계와 다음 단계
- 문서가 8건(4쌍)이라 **문서 단위** 점수(nDCG)는 쉽게 높게 나온다. 의미는 "공개 문서 1,000건 사이에서 마사회 규정을 맨 위로 찾는가"까지다.
- 같은 건의 개정안·개정전문은 버전 묶기(스펙 §9) 시험 자료로도 쓸 수 있다.
- 문서를 늘리면(다른 규정·공문·보고서) 질의도 함께 늘린다. 사용자가 문서를 `eval/downloads/` 에 넣으면 매니페스트·질의는 Claude 가 만든다.

## 검토 이력
